# 継続作業のチェックリスト

## 資料の読み順と権威
1. 最新ユーザー指示とAGENTS.md。
2. DECISIONS.md：会話で決めたこと、撤回・変更された旧方針。
3. HANDOVER.md：機能の実装状況、制約、最終確認。
4. OPERATIONS.md：接続方法とWindows依存の解消。
5. 画像制作の共通基準.md：画像品質、検索意図、大阪・神戸優先。
6. INITIAL-POSTS.json と assets/initial-20260930-1004/：初回素材と文章の参照用。公開状態は本番DBで確認する。これを入力して再予約してはいけない。

ソースはapp/、実稼働データは既存Cloudflare、認証情報はSecretsが正。ソースコピーだけで動作開始済みとしない。古い資料の「未確認」と最新の「確認済み」を混ぜない。

## 移行で持ち込まないもの
実DM、ユーザーの個人連絡先、認証値、DBコピー、Push購読、管理画面の個人情報を含むスクリーンショット、ローカル認証キャッシュ。これらをGitに置かなくても、正しく認証した既存本番へ接続すれば運用は継続できる。移行が必要なら別途暗号化経路と必要範囲を決める。

## 完了報告に必ず区別すること
「資料・コードがGitHubにある」「クラウド担当が実際に読み込んだ」「認証接続できた」「スケジュールが稼働した」「投稿・返信が成功した」は別の段階。現時点で全音声や全チャットの完全コピーは含まない。未取得の情報まで100%保証しない。
