# 会話の決定事項と変更履歴

2026-10-01。読み取れるチャットとローカル記録を照合した引継ぎ。以下は運用要件であり、全て実装済みという意味ではない。実装の制約はHANDOVER.mdを参照する。ユーザーの思考は「相手を尊重し、入力・読解・判断の手間を減らす」。固定文の機械的な反復ではなく判断手順を標準化する。

## 目的・地域・導線
- 求人と協力業者募集が主目的。工事依頼・見積相談・取引先の業務連絡も仕事DMとして扱う。
- 地域のメインは大阪・神戸。兵庫全域・大阪・近隣対応という既存情報は残す。大阪市だけに限定しない。
- プロフィールは更新しない。最初の接触の手間を最小化し、ボタン選択を入口として用意、詳しい情報は任意で受ける。
- ボタン文言：「求人について聞きたい」「協力業者として相談したい」「未経験でも働けますか？」。出ない場合は「求人」「協力業者」の一言を案内。
- 初期案はフォーム→公式LINEだったが、現在はInstagram DMで必要情報を聞き、公式LINEへ案内する。未接続フォームを導線に混ぜない。
- ストーリーのDM直リンクは実機で問題が繰り返されたため、プロフィール→メッセージを採用。Web版やPC風DM画面へ戻さない。画像のボタン風装飾をクリック可能と説明しない。
- LINE：株式会社指吸建設 @mii6462i、https://lin.ee/yhiJBfL 。管理者URL https://manager.line.biz/account/@mii6462i は利用者に送るURLではない。

## 投稿と画像
- 毎日投稿は必須という希望。ストーリー11時、通常投稿16時、JST。分単位の厳密さより継続を優先するが、障害時に成功を装わない。
- 日曜9時に直近の反応を調べ翌月曜〜日曜を準備。各投稿24時間前までに実物を管理画面に表示。承認操作を毎回必須にしない。
- 通常ストーリーは各回2〜3枚で表現にも変化。通常投稿は従来構成。提供写真があれば写真に合う内容＋募集・導線の2枚カルーセルを基本とするが、カルーセルは未実装。
- 画像提供がなくても新規生成を続ける。AI感のない仕上がり、品質維持、独創性、飽きない構図・配色・表現を重視。安い生成方式への無断置換や固定テンプレ量産をしない。
- 求人4／協力業者4／面白2を直近10公開枠の目安にする。枚数で比率を数えない。職人あるあるも、仕事と無関係の面白投稿も可。
- 人の注意を引く視覚設計を仮説として活用。科学的成果や効果を捏造せずスマホで検品する。架空の社員・実績・待遇を作らない。
- 大阪・神戸×土木・造成・外構×求人・協力業者募集という具体的な検索意図を考える。本文と関連タグへ自然に配置。キーワード詰め込みや検索順位の保証はしない。
- 毎回ダッシュボードの反応を確認し、良い投稿を調査して次に反映。24時間・7日など同程度の経過時間で比較。未取得指標や因果は作らない。

## 日曜の天気
- 兵庫県全域の建設業の人が翌週の段取りを考えられる週間カレンダーを1枚。募集地域が大阪・神戸中心でも天気の範囲を勝手に狭めない。
- 雨の日がひと目で分かる読みやすさを最優先。天気・降水確率を大きく、気温の参考地点、出典、対象期間、発表または確認時刻を明示。
- 神戸・阪神／播磨／但馬／丹波／淡路など地域差を考慮。単一地点を県全域の予報として扱わない。1枚に詰め込みすぎない。
- 日曜・祝日・振替休日は赤、土曜は青。曜日・祝日名も記載し色だけに頼らない。祝日は対象年の公式情報を確認。
- 土曜朝までに取得可能な予報で完成、日曜朝に更新確認。未発表値を作らず未発表と表示。週間で風がない場合は補完しない。作業可否や安全を断定しない。
- 以前の3枚案は撤回済み。10/4の旧frame2/3は取消済みで復活不可。

## eyeの判断手順・話し方
1. 最新の相談・質問・懸念と必要な履歴を読む。書かれていない事情を決めつけない。
2. 答えられる質問へ先に回答。既出情報を整理し、確認が必要なら1〜2点だけ尋ねる。初回から保険・資格等を列挙して審査のようにしない。
3. 短い相談には簡潔に、具体的な情報をまとめてくれた相手にはお礼と重要点の受け止めを返す。質問済み事項を再質問しない。
4. 担当者が相談を理解できる情報があれば早めにLINEへ。経験・地域・希望、工種・地域・人数・時期などは目安で、全部を必須にしない。
5. 未確認事項は未確認として引き継ぐ。LINE移行を相手の同意なく決定済みと言わない。「ご相談いただけますか」等の依頼として案内。
- 初回名乗りは「ご連絡ありがとうございます！DM受付のeyeと申します。」という考え方。AIと明かし軽い驚きや笑いを添える。苦情などに冗談を入れない。
- 固定テンプレの連続、わざとの誤字、架空の人間体験、過剰な敬語、無理な関西弁は禁止。
- 冗談は基本最初だけ。相手が冗談を続ける場合も状況に応じて対応し、目的を見失わない。
- 4〜5往復は目安。最初から具体的なら1〜3通で案内。即LINE希望はすぐ案内。必要なら7往復超でも可。回数稼ぎをしない。
- 前後の質問が両方有効なら両方を考慮し、訂正・撤回された内容は引きずらない。新着が来たら古い返信案は送らない。
- LINE案内後もお礼や追加質問に多少は返す。再度の催促・リンク連投・無用な質問で引き延ばさない。
- 金額・単価・給与・契約・採用可否などは未確認のまま確約しない。人と話したい希望には謝罪し担当者へ通知、AI停止。
- BOTと判断できる場合は停止・報告。短文・外国語・定型文だけで断定しない。
- アプリで要約、既知・未確認情報、最新相談、判断理由、対応メモ、送信結果を確認できること。LINEの相手との照合・引継ぎは確実に。

## アプリ・通知・課金
- 主端末はiPhone。ホーム画面から使うPWA。Instagramを連想する配色、不要ボタンを減らす。サンプル表示・スマホでの投稿制作ボタン・大きな通知時間表示は不要。
- 同アカウントはまとめて返信済みを折りたたみ、未返信を見やすく展開。送信者は可能ならアカウント名。
- 対応済みDMの削除とeye会話カードの一覧削除は別。eye削除でInstagram原文は消さず、直後の取消が可能。送信結果不明は削除で隠さない。
- 仕事DM通知は9〜19時30分毎。無関係な私信・スタンプ・明白なスパム・無関係営業を通知しない。ロック画面に本文等は出さない。
- eye通常返信は9時以上19時未満、即時生成。夜間は翌朝。通知間隔と返信タイミングを混同しない。
- 無料希望。有料料金を質問したが契約承認ではない。「MAX」は無料枠までの拡大。アプリの30処理制限は撤廃、モデルと検品は維持。
